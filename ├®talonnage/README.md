# Calibration data (13 external anchors)

Each subfolder corresponds to one anchor in Table 10 of the manuscript.
`noise/` = "Voynich, fully permuted" (pure-noise control) in the manuscript's naming.
`aps_calibration.py` is the unmodified pipeline script used to produce all per-anchor results.
The Voynich manuscript's own signal (Table 9) is not duplicated here; it is taken directly
from the manuscript text and is not a separate calibration run.
